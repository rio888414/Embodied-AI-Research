# 智元 Genie 科研合作 · 论文引用追踪平台

面向内外部协作的具身智能论文引用追踪平台：把「精灵 Genie」相关论文按智元产品关联方式归类，一屏看清引用分布、引用增长与高质量引用明细。

## 🔗 在线访问

**<https://genie-research.app.workbuddy.host/>**

> 打开即可直接使用，无需安装、无需登录。建议使用 Chrome / Edge / Safari 等现代浏览器访问，桌面端体验最佳。

---

## 核心功能

### 1. 科研引用概览

- **高质量论文引用分布**：环形图呈现各关联类型的论文数量与占比，中心显示收录总数。
- **高质量论文引用月度变化**：柱状图按论文发表月份统计，自 2025 年 9 月起展示，香槟金为非「仅引用」板块。
- **谷歌学术引用次数统计**：按论文汇总各期引用读数与最新一期数值，附总计行。

### 2. 高质量引用明细

通过顶部控件在六个板块间切换，逐篇查看：

| 板块 | 说明 |
|---|---|
| Genie Internal | 智元 Genie 内部文章 |
| AGIBOT WORLD + G-Series | 使用 AGIBOT WORLD 数据集及 G 系列本体 |
| AGIBOT WORLD Only | 仅使用 AGIBOT WORLD 数据集 |
| Genie Sim | 使用 Genie Sim 仿真平台 |
| UniVLA | 使用 UniVLA 进行对比 |
| Citation Only | 仅引用提及（仅呈现论文名称与跳转链接） |

每篇论文卡片包含：论文标题、论文团队（多团队并列展示）、发表日期、跳转原文链接、文章核心内容、智元产品关联情况。

### 3. 论文解析 Agent

右下角悬浮入口，粘贴论文链接即可自动完成解析：

- 支持 arXiv 链接（abs / pdf / html）、裸 arXiv 编号、DOI、OpenAlex ID，以及直接粘贴论文标题
- 自动提取并返回：论文标题、论文团队（高校 / 团队）、跳转链接、约 100 字核心研究内容、智元产品关联情况
- 解析结果自动写入数据库，可在后台继续编辑

### 4. 数据后台

页面底部提供管理入口，支持对论文与引用数据的新增、编辑、删除。

---

## 数据说明

- 收录论文经过归并分类展示；未明确归类的条目单独标注为「其他引用」兜底，不计入主图占比。
- 引用数据来源于 Google Scholar，按周期人工核对更新。
- 论文元数据通过公开学术数据源获取（OpenAlex、DataCite、Crossref）。

---

## 技术说明

- 前端为纯静态页面（HTML / CSS / JavaScript），无构建步骤，`index.html` 即入口。
- 数据存储与论文解析依托云服务，公开只读访问；后台修改需通过页面底部入口验证。
- 论文解析 Agent 由免密钥大模型调用完成字段抽取。

## 本地运行

```bash
# 在项目目录下启动任意静态服务器即可
python -m http.server 8080
# 然后访问 http://localhost:8080/index.html
```
